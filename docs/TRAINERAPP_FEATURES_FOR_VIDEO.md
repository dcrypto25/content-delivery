## 💡 Pro Tips

**For Screenshots:**
- Use real data (fake names/numbers are fine)
- Show features mid-action (not empty states)
- Capture "wow moments" (completed goals, AI responses, progress graphs)
- Include both light & dark mode if possible
- Vertical orientation (1080x1920) preferred

**For Best Results:**
- Mix of empty → filled states shows before/after
- Include loading states (adds realism)
- Show errors/validation (makes it feel real)
- Capture celebration moments (goal reached, streak milestones)
